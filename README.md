# Aliza's Birthday Experience

This project is dedicated to creating a romantic and immersive web experience for Aliza's birthday on October 23, 2026. The goal is to tell the story of our relationship through an interactive format that feels personal and heartfelt.

## Project Structure

- **index.html**: The main HTML document that structures the content and links to the CSS and JavaScript files.
- **style.css**: Contains styles for the web experience, defining the visual appearance to create a romantic and elegant atmosphere.
- **script.js**: Manages interactive elements of the site, handling video loading, transitions, and user interactions.
- **images/**: Directory for storing all images used in the project.
- **videos/**: Directory for holding all video files displayed throughout the experience.
- **music/**: Directory for containing music files that will play during the experience.
- **assets/**: Additional resources for the project:
  - **fonts/**: Custom font files used in the project.
  - **icons/**: Icon files used for UI elements.
  - **animations/**: Animation files or scripts used to enhance the visual experience.
- **.gitignore**: Specifies files and directories to be ignored by Git.
- **.vscode/**: Contains settings specific to the Visual Studio Code editor.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the project in your preferred code editor.
3. Ensure all assets (images, videos, music) are placed in their respective directories.
4. Open `index.html` in a web browser to view the experience.

## Publish with GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` deploys the site whenever changes are pushed to the `main` branch.

1. Push this project to a GitHub repository.
2. In the repository, open **Settings > Pages** and select **GitHub Actions** as the build and deployment source.
3. Push to `main` or run the **Deploy birthday site to GitHub Pages** workflow manually from the **Actions** tab.
4. Find the permanent site URL under **Settings > Pages** or in the completed workflow run.

The birthday page and its media are personal. Anyone who can access the published URL may view the page and its videos. GitHub Pages sites are public, so publish only if that is acceptable.
